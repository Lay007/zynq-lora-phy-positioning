# FPGA workspace

This directory will contain synthesizable PL blocks and their verification.
Planned top-level areas are `rtl/`, `tb/`, `constraints/`, `scripts/`, and
`ip/`. Generated Vivado products belong under `fpga/build/` and are ignored.

Every DSP block should define:

- sample format, scaling, rounding, and saturation;
- AXI-Stream framing and backpressure behavior;
- latency and throughput;
- reset and clock-domain assumptions;
- golden vectors generated by the Python package;
- assertions and boundary-condition tests.
