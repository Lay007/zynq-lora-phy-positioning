# Серия режимов LR1121 → ZynqSDR

[English summary](../../../docs/hardware-sweep-2026-08-02.md) ·
[Полный отчёт](../../../docs/ru/hardware-sweep-2026-08-02.md)

В каталоге находятся 27 непрерывных OTA-записей LoRa/CSS в формате CF32:
комплексные `float32`, little-endian, чередование I/Q. Общий объём raw IQ —
469 762 048 байт (448 MiB). Файлы `.cf32` хранятся через Git LFS.

Матрица включает SF5…SF12, BW 62,5/125/250/500 кГц, CR 4/5…4/8,
мощность 0/−5/−8/−9 dBm, payload 12…220 байт, preamble 8…32 символа,
CRC off, sync word `0x34` и inverted IQ. В 27 записях выполнено 70 передач;
LR1121 подтвердил каждую из них кодом `state=0`.

- `manifest.json` содержит профиль, настройки приёмника, TX-подтверждения,
  SHA-256, метрики MATLAB и происхождение каждого файла.
- `summary.csv` — плоская таблица основных параметров и метрик.
- Имена `.cf32` совпадают с именами режимов из sweep-конфигурации.

При упаковке размер и SHA-256 каждого исходного файла проверены, затем хеш
повторно рассчитан у копии. MATLAB R2025a создал 27 отчётов с ограничением по
фактически заданным SF/BW: совпали 27/27 SF и 27/27 BW, ни одна выбранная
посылка не касается начала или конца записи. Оценка SNR лежит в диапазоне
43,8…53,4 dB.

Это сильносигнальный инженерный набор, а не калиброванный BER/PER или
sensitivity test. Для BW500 при Fs = 2 МГц слепая оценка центра дала аномальный
CFO около +52 кГц; этот режим нужно повторить с центром RX на несущей и
отдельно проверить широкополосный оцениватель.
