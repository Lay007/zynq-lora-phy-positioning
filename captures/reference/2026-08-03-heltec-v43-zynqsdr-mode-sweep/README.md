# Серия режимов Heltec V4.3/SX1262 → ZynqSDR

[English summary](../../../docs/hardware-sweep-2026-08-03-heltec-v43.md) ·
[Полный отчёт](../../../docs/ru/hardware-sweep-2026-08-03-heltec-v43.md)

В каталоге находятся 27 непрерывных OTA-записей в формате CF32: комплексные
`float32`, little-endian, чередование I/Q. Общий объём raw IQ — 469 762 048
байт (448 MiB). Файлы `.cf32` хранятся через Git LFS.

Плата была электрически определена как Heltec V4.3 (`GPIO5 HIGH: 0/32`).
Прошивка 0.2.0 использовала transmit bypass KCT8103L без внешнего PA и настройки
SX1262 −5/−8/−9 dBm. Матрица включает SF5…SF12, BW
62,5/125/250/500 кГц, CR 4/5…4/8, варианты payload/preamble, CRC off,
sync word `0x34` и inverted IQ. В выбранных записях выполнено 70 передач;
каждая подтверждена `state=0`.

- `manifest.json` содержит настройки, TX-подтверждения, SHA-256, MATLAB-метрики
  и происхождение каждого файла;
- `summary.csv` содержит плоскую таблицу параметров и оценок;
- `decode-summary.csv` содержит результат сквозного MATLAB-декодирования
  одной выбранной посылки из каждого файла;
- `packet-performance.csv` содержит acquisition/header/CRC/BER/PER-поля для
  всех 70 подтверждённых передач;
- `case-performance.csv` агрегирует результаты по 27 режимам;
- `performance-summary.json` содержит общий машиночитаемый итог;
- имена `.cf32` совпадают с именами случаев sweep-конфигурации.

Размер и SHA-256 проверены у каждого исходного файла и повторно у копии.
MATLAB создал 27 отчётов. Для 26 режимов границы и преамбула найдены уверенно;
автоматические границы/CFO/score режима BW 500 кГц недостоверны из-за известного
ограничения сегментации и сохранены только как регрессионный пример.

Первичный single-packet отчёт проверил header checksum и payload CRC у 24 из
27 выбранных посылок. Для `sf7-bw500` ещё неустойчив acquisition при BW,
занимающей половину Fs. Этот исторический результат относится к одной
автоматически выбранной посылке; полный soft/multi-packet отчёт приведён ниже.

Multi-packet/soft evaluation анализирует все 70 передач: 68 acquisition,
66 valid header, 60 побитно совпавших payload; soft decoder восстановил два
пакета сверх hard decoder. Консервативный PER равен 10/70 = 14,29%. Подробные
определения находятся в
[`docs/ru/lora-packet-decoder.md`](../../../docs/ru/lora-packet-decoder.md).

Набор не является калиброванным измерением BER/PER, sensitivity или мощности.
