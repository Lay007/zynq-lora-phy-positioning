# IQ captures

Raw captures are intentionally not committed by default. For each shared test
vector, include a small sample or a retrieval location plus:

- SHA-256 checksum and byte format;
- sample rate and center frequency;
- I/Q order, endianness, scaling, and channel count;
- radio configuration and gain mode;
- transmitter packet configuration and payload;
- capture time, setup identifier, and known impairments.
