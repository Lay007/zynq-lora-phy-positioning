# Эталонный передатчик Heltec WiFi LoRa 32 V4 + SX1262

Прошивка реализует тот же serial-протокол, что и передатчик LR1121: `show`,
`set ...`, `payload`, `send`, `start` и `stop`. После загрузки передатчик всегда
остановлен. BOOT является только аварийной остановкой и не может включить RF.

До передачи нужно подтвердить антенну и маркировку PCB V4.2/V4.3. У ревизий
разные внешние FEM. Текущая прошивка удерживает GPIO46 и GPIO5 в низком уровне,
не включает внешний PA, сообщает `fem=bypass` и ограничивает настройку SX1262
диапазоном −17…0 dBm.

Проверенная плата на COM10 имеет MAC `10:BD:A3:5A:57:90`. Её полный заводской
образ 16 MiB сохранён до прошивки:

```text
G:\Programs\7020\backups\20260802T200300-heltec-wifi-lora32-v4-sx1262\flash-full-16MiB.bin
SHA-256 A23B73E914815044601FE549FB8C2BC8DF8A5F9701EF5A194271C83130E3C28E
```

Сборка и загрузка:

```powershell
cd firmware/heltec-v4-sx1262-tx
pio run
pio run --target upload --upload-port COM10
```

Безопасная проверка, не создающая радиопередачу:

```text
version
show
help
stop
```

На стенде проверена версия `0.1.1`: SX1262 инициализируется, `show` сообщает
`running=no fem=bypass`. Команды `send` и `start` до подтверждения ревизии и
антенны не использовать.
