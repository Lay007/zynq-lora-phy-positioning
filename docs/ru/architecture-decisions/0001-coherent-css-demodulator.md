# ADR-0001: Когерентный FFT-correlator с пакетным fallback

**Статус:** принято
**Дата:** 2026-08-08

## Контекст

Исходный передискретизированный приёмник выполнял dechirp и `N=2^SF` FFT для
каждой из `L=Fs/BW` фаз, затем складывал мощности. При `L=8` он проигрывал
точному matched filter `5,33 dB` при BER `1e-2` и `6,03 dB` при BER `1e-3`.
Банк из `N` временных корреляторов слишком дорог как граница HDL.

Ранний nominal coherent-прогон устранил разрыв в AWGN, но декодировал только
118 из 130 передач SX1262→ZynqSDR. Дальнейшая проверка обнаружила прежде всего
неоднозначность синхронизации, а не доказанное несовпадение формы chirp:
dechirp-пик upchirp смешивает целочиповый timing и CFO. Знаковые bins
upchirp/downchirp разделяют их, поскольку timing меняет знак, а CFO — нет.

## Решение

Первым кандидатом для Simulink/HDL выбран точный FFT-correlator. Для `M=N·L`:

```text
FFT длины M
  → умножение на комплексно сопряжённый спектр опоры
  → сумма частотных bins m+rN, r=0…L−1
  → прямой FFT длины N
  → magnitude и поиск максимума
```

Результат совпадает с корреляциями matched filter в точках `−kL` и численно
эквивалентен независимому эталону с полным IFFT.

MATLAB-приёмник пакетов дополнительно оценивает выровненный по фазе шаблон по
повторяющимся upchirp преамбулы и для каждой временной гипотезы проверяет
FFT-correlator и legacy polyphase. Результат выбирается по header и CRC.
Адаптивная опора и fallback пока остаются вне первого HDL DUT.

## Рассмотренные варианты

| Вариант | AWGN | Реальные IQ | Стоимость HDL | Решение |
|---|---|---|---|---|
| Первая фаза децимации | теряет выигрыш `L` | простой | низкая | отклонён |
| Сумма мощностей polyphase FFT | проигрыш 5–6 dB при `L=8` | 130/130 | средняя | оставить fallback |
| Банк временных шаблонов | оптимален | чувствителен к mismatch | очень высокая | только эталон |
| FFT-correlator | точный и оптимальный | 130/130 после joint timing/CFO | измерить | первый DUT |

## Последствия

- Разрыв floating-point AWGN относительно эталона равен `0 dB`.
- DUT требует framing целого символа, FFT длины `M`, ROM/RAM коэффициентов,
  сумму частотных секций и FFT длины `N`.
- В Simulink нужно проверить разделение ресурсов двух FFT при требуемой
  пропускной способности.
- AWGN недостаточно для вывода об эфирной устойчивости: регрессия по
  сохранённым IQ обязательна.
- Текущий результат — 130/130, все 130 выбрали FFT-correlator. Polyphase
  остаётся защитной ветвью, но не использовался.

## Следующие действия

1. Экспортировать комплексные golden-векторы каждого этапа.
2. Задать streaming order, buffering, `valid/ready` и reset behavior.
3. Квантовать коэффициенты опоры и оба FFT.
4. Измерить latency, ресурсы и стоимость сохранения fallback-метрик.
5. Добавить sweep CFO/SFO/timing/multipath до удаления fallback.
