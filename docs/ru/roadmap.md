# Дорожная карта

[English version](../roadmap.md)

Этап закрывается только после появления измеримого подтверждения в репозитории.
Календарные сроки намеренно не используются.

## M0 — Воспроизводимый репозиторий

- [x] Структура MATLAB и автоматические тесты CSS float-модели.
- [x] Вспомогательные Python-проверки CSS, ToA и TDoA.
- [x] Архитектура, требования к стенду и шаблоны экспериментов.
- [x] Записана и проверена по SHA-256 серия из 27 режимов LR1121 → ZynqSDR:
  SF, BW, CR, мощность, длина payload/preamble, CRC, sync word и IQ polarity.
- [x] Собрана и безопасно инициализирована остановленная по умолчанию прошивка
  Heltec V4/SX1262; подключённая плата электрически определена как V4.3 и
  проверен transmit bypass KCT8103L.
- [x] Записана, проверена по SHA-256 и опубликована через Git LFS серия из 27
  режимов Heltec V4.3/SX1262 → ZynqSDR.

Критерий: чистый checkout проходит MATLAB- и Python-тесты.

## M1 — MATLAB floating-point PHY и позиционирование

- [x] Генерация CSS upchirp/downchirp.
- [x] Модуляция символа, dechirp/FFT, AWGN и CFO.
- [x] LoRa packet encode/decode с жёсткими решениями: explicit header,
  whitening, interleaving, Hamming, CRC и Gray/CSS mapping.
- [x] Обнаружение исследовательской преамбулы `8 up + 2 down` без известного
  начала кадра.
- [x] Оценка и компенсация CFO на синтетическом кадре.
- [x] Воспроизводимые uncoded BER/SER и coded BER/PER.
- [x] Версионный golden-вектор SF7/CR1 с промежуточными значениями.
- [x] Стандартный LoRa sync word, downchirp transition и границы пакета,
  включая SFD из 2.25 downchirp и padding SX126x для низких SF.
- [x] SFO, дробное время, многолучёвость и искажения AD936x.
- [x] Грубый и дробный ToA с оценкой bias/jitter.
- [x] Откалиброванные TDoA-наблюдения и 2D-мультилатерация.
- [x] Запись Heltec/SX1262 при BW 125 кГц, SF7 и оценка MATLAB-моделью границ
  пакета, BW, SF, несущей/CFO, SNR и качества преамбулы.
- [x] Декодирование стандартных эфирных символов и payload SX1262
  MATLAB-моделью.
- [x] Декодирование всех разделённых по энергии всплесков одной записи и
  сопоставление результатов с логом передатчика для расчёта BER и PER пакетов.
- [x] Мягкое декодирование по max-log: символы, деинтерливер и код Хэмминга,
  с учётом числа пакетов, восстановленных сверх жёстких решений.
- [x] HDL-ориентированный FFT-correlator, алгебраически эквивалентный matched
  filter в AWGN; после joint timing/CFO все 130/130 реальных передач выбирают
  его, а CRC-проверяемый polyphase остаётся защитной ветвью.
- [x] Формирование и приём полных пакетов в непрерывном настроенном IQ:
  energy/chirp candidates, implicit header, ADC quantization, false alarms и
  end-to-end BER/PER.

Критерий выполнен. Многоуровневая детерминированная база превышает 1000
испытаний: 324 синтетических end-to-end пакета, 130 реальных пакетов SX1262,
500 испытаний дробного ToA и 3000 решений калиброванного TDoA. Исходные данные,
метрики и граница configuration-aided модели приведены в
[приёмке MATLAB M1](matlab-m1-acceptance.md).

## M2 — Исполняемая модель Simulink

- [x] Воспроизвести FFT-correlator потоковой моделью: FFT `N·L`, умножение на
  спектр опоры, сумма `L` секций и FFT `N`.
- [x] Определить framing и управление потоком; отказ от backpressure опирается
  на измеренную полную пропускную способность.
- [x] Ввести fixed-point типы, округление, насыщение и overflow policy и
  выполнить sweep разрядности.
- [x] Сравнить каждый этап с MATLAB golden-векторами.
- [x] Зафиксировать latency и throughput.
- [x] Прогнать через fixed-point модель окна символов из реальных записей
  SX1262.
- [x] Пройти проверки HDL Coder: `checkhdl` даёт ноль ошибок на fixed-point
  корреляторе и на DUT совместной оценки timing/CFO.
- [ ] Зафиксировать reset behavior: порта reset в моделях пока нет.
- [ ] Смоделировать acquisition: chirp-aware детектор преамбулы, проверку
  sync/SFD и кадрирование пакета.
- [ ] Оставить association/TDoA solver вне HDL DUT и проверить интерфейс
  timestamp/metadata, который описан, но ещё не реализован.

Критерий: Simulink совпадает с MATLAB в документированных допусках и проходит
проверки HDL Coder. Измеренное на сегодня приведено в
[приёмке M2](simulink-m2-acceptance.md); этап остаётся открытым по
неотмеченным пунктам выше.

- [ ] Захват грубого счётчика отсчётов в PL.
- [ ] Дробный ToA и confidence metric.

## M6 — Синхронный TDoA трёх приёмников

- [ ] Проверить входы общей опоры и синхронизации каждой ZynqSDR.
- [ ] Подать общий clock и epoch/PPS непосредственно в PL.
- [ ] Измерить постоянную межканальную задержку и drift.
- [ ] Сопоставить пакеты трёх станций и решить калиброванный 2D TDoA.
- [ ] Сравнить координаты с измеренной геодезической истиной.

Критерий: сначала кабель, затем помещение/поле; CDF горизонтальной ошибки,
геометрия, версия калибровки и бюджет неопределённости.

| Область | Метрики |
|---|---|
| Радиолиния | sensitivity, PER, CFO/SFO tolerance |
| Синхронизация | вероятность обнаружения, false alarm, bias/jitter |
