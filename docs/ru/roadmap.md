# Дорожная карта

[English version](../roadmap.md)

Этап закрывается только после появления измеримого подтверждения в репозитории.
Календарные сроки намеренно не используются.

## M1 — MATLAB floating-point PHY и позиционирование

- [x] Генерация CSS upchirp/downchirp.
- [x] Модуляция символа, dechirp/FFT, AWGN и CFO.
- [x] LoRa packet encode/decode с жёсткими решениями: explicit header,
  whitening, interleaving, Hamming, CRC и Gray/CSS mapping.
- [x] Обнаружение исследовательской преамбулы `8 up + 2 down` без известного
  начала кадра.
- [x] Оценка и компенсация CFO на синтетическом кадре.
- [x] Воспроизводимые uncoded BER/SER и coded BER/PER.
- [x] Версионный golden-вектор SF7/CR1 с промежуточными значениями.
- [x] Стандартный LoRa sync word, downchirp transition и границы пакета,
  включая SFD из 2.25 downchirp и padding SX126x для низких SF.
- [x] SFO, дробное время, многолучёвость и искажения AD936x.
- [x] Грубый и дробный ToA с оценкой bias/jitter.
- [x] Откалиброванные TDoA-наблюдения и 2D-мультилатерация.
- [x] Запись Heltec/SX1262 при BW 125 кГц, SF7 и оценка MATLAB-моделью границ
  пакета, BW, SF, несущей/CFO, SNR и качества преамбулы.
- [x] Декодирование стандартных эфирных символов и payload SX1262
  MATLAB-моделью.
- [x] Декодирование всех разделённых по энергии всплесков одной записи и
  сопоставление результатов с логом передатчика для расчёта BER и PER пакетов.
- [x] Мягкое декодирование по max-log: символы, деинтерливер и код Хэмминга,
  с учётом числа пакетов, восстановленных сверх жёстких решений.
- [x] HDL-ориентированный FFT-correlator, алгебраически эквивалентный matched
  filter в AWGN; после joint timing/CFO все 130/130 реальных передач выбирают
  его, а CRC-проверяемый polyphase остаётся защитной ветвью.
- [x] Формирование и приём полных пакетов в непрерывном настроенном IQ:
  energy/chirp candidates, implicit header, ADC quantization, false alarms и
  end-to-end BER/PER.

Критерий выполнен. Многоуровневая детерминированная база превышает 1000
испытаний: 324 синтетических end-to-end пакета, 130 реальных пакетов SX1262,
500 испытаний дробного ToA и 3000 решений калиброванного TDoA. Исходные данные,
метрики и граница configuration-aided модели приведены в
[приёмке MATLAB M1](matlab-m1-acceptance.md).

- [x] Сравнить каждый этап с MATLAB golden-векторами.
- [x] Зафиксировать latency и throughput.
- [x] Прогнать через fixed-point модель окна символов из реальных записей
  SX1262.
- [x] Пройти проверки HDL Coder: `checkhdl` даёт ноль ошибок на fixed-point

- [x] Зафиксировать reset behavior: `resetIn` возвращает DUT в исходное
  состояние, что доказано вторым сигналом после reset в середине потока.
- [x] Смоделировать приём преамбулы и sync word по потоку символов; точное
  совпадение с MATLAB на 615 последовательностях.
- [x] Смоделировать слепое обнаружение начала пакета по свободно идущему потоку
  символов; точное совпадение с MATLAB на 2000 символах и всех 256 sync word.
  Скользящая корреляция не нужна: бин преамбулы равен смещению в целых чипах,
  поэтому обнаружение стоит 0 умножителей и 0 RAM.
- [x] Выровнять сетку окон по `chipsToBoundary` и собрать коррелятор, детектор
  и выравнивание в один front-end. Пакет на неизвестном смещении отсчётов
  захватывается и демодулируется в тот же payload, что и выровненный;
  проверено на четырёх смещениях.
- [x] Проверить пару downchirp SFD, переиспользуя собственный ROM опоры
  коррелятора по инвертированному адресу вместо второй таблицы, и построить
  автомат кадрирования с перевзводом. Побитовое совпадение с MATLAB на 390
  символах, 7 пакетах и 15 отказах.
- [x] Построить DUT проверки SFD; побитовое совпадение с MATLAB на 660 группах
  для SF5/SF7/SF9, стимул преимущественно из групп, которые он обязан
  отвергнуть.
- [ ] Оставить association/TDoA solver вне HDL DUT и проверить интерфейс
  timestamp/metadata. Грубый счёт отсчётов и его флаг валидности реализованы и
  проверены; дробный ToA — нет, поскольку требует matched filter на частоте
  отсчётов, относящегося к acquisition.

Критерий: Simulink совпадает с MATLAB в документированных допусках и проходит
проверки HDL Coder. Измеренное на сегодня приведено в
[приёмке M2](simulink-m2-acceptance.md); этап остаётся открытым по
неотмеченным пунктам выше.

- [x] Выполнить out-of-context синтез с отчётами по ресурсам и timing

## M4 — Символьный приёмник ZynqSDR

- [x] Подключить сгенерированное ядро к форматированному RX1-потоку AD9361 в
  Vivado. Исходная композиция, gpreg map, CDC-regression, полный board
  implementation, cold boot с SD и smoke test живого RX DMA готовы.
- [x] Подтвердить первый эфирный acquisition от Heltec WiFi LoRa 32 V4.3 на
  868,1 МГц, BW 125 кГц, SF7, CR 4/5. RX1 записал пакет с ожидаемой ориентацией
  IQ, а при ручном усилении 50 dB в PL установился sticky packet-start. Sequence
  metadata осталась нулевой, поэтому восстановление символов/ToA этим не закрыто.
  Протокол: `docs/clg400-hardware-session-2026-09-02.md`.
- [x] Локализовать и замкнуть однопакетный hardware timestamp path. Регрессия
  с живой записью IQ воспроизвела `read_miss` истории 16k; образ с историей 65k
  протрассирован с WNS +0,211 нс и успешно холодно загрузился. Один пакет Heltec
  выдал sequence 1, coarse/fractional ToA, все stage-биты и ни одного sticky
  error. Это доказательство связности, а не приёмочный прогон 1000 пакетов.
- [x] Добавить замороженную PL-трассу из 128 символьных решений и программный
  hard decoder. Timestamp ABI страницы 0 не изменён; RTL-регрессия проверяет
  BRAM и gpreg-страницу, Python golden-векторы — explicit header, FEC,
  whitening и payload CRC.
- [x] Декодировать реальный эфирный payload Heltec при BW 125 кГц и SF7. Одна
  замороженная трасса дала валидный explicit header с валидной checksum,
  валидный LoRa payload CRC и сигнатуру `ZLP1` с тем же sequence number,
  который передатчик сообщил для этой единственной команды `send`. Из десяти
  сохранённых попыток header восстановился во всех, payload — в одной: сетка
  символов не выравнивается по пакету, поэтому дробный остаток портит отдельные
  символы payload. См. `docs/clg400-payload-session-2026-09-03.md`.
- [x] Подать resync коррелятора от детектора, чтобы сетка выравнивалась по
  пакету. Подтверждено на плате: все шестнадцать сохранённых захватов сообщают о
  перевыравнивании и декодируются с нулевой поправкой бина там, где прошлый
  образ требовал четверть символа. Доля принятых payload за этим не последовала:
  3 из 16 против 1 из 10.
- [ ] Объяснить односторонний сдвиг решений на +1 бин. Он зависит от
  сообщённого бина: 56% по обе стороны от стыка шкалы и 10–18% в середине, и
  разбросан по пакету. Шум до −10 дБ, суб-чиповое выравнивание, разрядности
  Q10/16 бит и CFO до 8 бинов прогнаны через модель по отдельности — ни один не
  воспроизводит картину; догадка по чётности померена на тех же захватах и
  отвергнута на 4 из 13. Дальше — снять сырое IQ через RX DMA и прогнать
  эталонный приёмник по тому же пакету, о котором PL принял решение: это
  разделит дефект коррелятора и дефект выше по тракту.
- [ ] Измерить symbol error rate и PER на контролируемом кабельном тракте.
- [ ] Расширить до полного пакетного PHY и двусторонней совместимости.
- [ ] Измерить PER по SNR/мощности и допуски CFO/SFO.

Критерий: не менее 1000 аппаратных пакетов с метриками и совпадающими
контрольными точками MATLAB/Simulink/Verilog.
