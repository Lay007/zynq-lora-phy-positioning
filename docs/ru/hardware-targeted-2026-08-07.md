# Целевой аппаратный прогон Heltec V4.3 от 7 августа 2026 года

[English version](../hardware-targeted-2026-08-07.md)

В фиксированной OTA-геометрии записаны пять IQ-файлов через Git LFS и 130
подтверждённых передач SX1262. Полный набор, SHA-256 и команды воспроизведения:
[`captures/reference/2026-08-07-heltec-v43-zynqsdr-targeted`](../../captures/reference/2026-08-07-heltec-v43-zynqsdr-targeted/README.md).

Основные выводы:

- контрольный SF7/BW125 декодирован 10/10;
- адаптивная оценка локального фона обнаруживает 30/30 пакетов SF5 и 30/30
  пакетов SF6; payload совпал для 26/30 в каждом режиме, а оставшиеся потери
  локализованы в header/CRC, а не в activity detector;
- BW500 работает при правильной записи с Fs=4 Мвыб/с: декодировано 10/10 вместо
  0/2 в старой записи при Fs=1 Мвыб/с;
- серия из 50 SF7-пакетов дала остаточное стандартное отклонение 18,50 мкс
  после аффинной компенсации часов TX/RX, но это ещё не абсолютная калибровка
  ToA.

Следующая алгоритмическая задача — разобрать метрики символов, timing и
остаточный CFO для восьми ошибок low-SF header/CRC, затем проверить улучшение
на управляемом SNR sweep. Следующий аппаратный этап ToA потребует безопасного
кабельного тракта с рассчитанным ослаблением и timestamp ближе к RF, чем ESP32
`millis()`.
