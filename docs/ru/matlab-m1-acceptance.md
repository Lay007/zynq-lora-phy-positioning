# Приёмка floating-point MATLAB-модели M1

[English version](../matlab-m1-acceptance.md)

Этап M1 завершён на границе алгоритмов с плавающей точкой. Настраиваемый
приёмник принимает непрерывный комплексный IQ, находит полные LoRa-пакеты,
разделяет временную и частотную ошибки, декодирует header и payload и считает
acquisition, pre-FEC, CRC, BER и PER. В том же авторитетном MATLAB-слое теперь
есть дробный ToA, калиброванные TDoA-наблюдения и взвешенный solver 2D
мультилатерации. Simulink намеренно не входит в эту приёмку.

## Контракт приёмника

```text
непрерывный настроенный IQ
  -> energy-кандидаты + chirp-кандидаты
  -> проверка повторных upchirp, sync word и downchirp SFD
  -> совместная оценка timing/CFO по upchirp и downchirp bins
  -> пакет с explicit или implicit header
  -> deinterleaving, FEC, dewhitening, CRC, payload
  -> метрики обнаружения, false alarm, BER и PER
```

Chirp-детектор проверяет переход sync word и два downchirp SFD. Поэтому он
видит пакет ниже энергетического порога, но не принимает повторяющиеся символы
payload за преамбулу. Energy- и chirp-кандидаты объединяются без взаимного
подавления, в том числе когда сильный пакет виден по энергии, а слабый — только
по структуре chirp.

По одному upchirp нельзя однозначно разделить целочиповый timing offset и CFO:
оба сдвигают максимум после dechirp. У downchirp знак временного слагаемого
меняется, а знак CFO — нет. Поэтому half-sum знаковых up/down bins даёт CFO, а
half-difference — временную поправку. Именно это исправление сделало
когерентную ветвь детерминированной на сохранённых реальных IQ.

## Воспроизведение

MATLAB R2025a, каталог `model/matlab`:

```matlab
results = run_tests;
assertSuccess(results);

addpath examples
report = run_m1_acceptance;
```

Команда сохраняет исходные CSV/MAT в `docs/data`, а изображения — в
`docs/images`. SNR поточной кампании определён как номинальная мощность
активного пакета к мощности комплексного шумового отсчёта; паузы между
пакетами не занижают опорную мощность.

Sensitivity sweep использует `L=Fs/BW=8`, CR 4/5, payload 16 байт и 20 пакетов
на точку. Во всех строках получены ноль несопоставленных false alarms и ноль
дубликатов.

| 5 | -14 / -12 / -10 / -8 | 0 / 2 / 18 / 20 | 1 / 0,95 / 0,20 / 0 |
| 7 | -18 / -16 / -14 / -12 | 1 / 16 / 20 / 20 | 1 / 0,90 / 0 / 0 |
| 9 | -24 / -22 / -20 / -18 | 0 / 10 / 20 / 20 | 1 / 0,95 / 0,05 / 0 |

![End-to-end sensitivity поточного LoRa-приёмника](../images/lora-end-to-end-sensitivity.png)

Матрица режимов охватывает все 32 комбинации
`SF5...SF12 x CR 4/5...4/8` при `L=4`, по два пакета: 64/64 пакетов приняты
и декодированы с нулевым PER. Четыре impairment-сценария по пять пакетов также
дали 20/20 точных payload: baseline; CFO 1,5 кГц вместе с SFO 20 ppm и задержкой
1,75 отсчёта; multipath с дробной задержкой; I/Q imbalance, DC offset,
12-битное квантование ADC и контроль clipping.

Независимой регрессией остаются сохранённые записи SX1262 -> ZynqSDR. Все
130/130 передач проходят acquisition, header, CRC и точное сравнение payload;
pre-FEC BER равен 2,227%. После совместной коррекции timing/CFO все 130 выбрали
FFT-correlator, сохранённый защитный polyphase fallback не потребовался. Старые
результаты 118/130 и split 56/74 объяснялись прежде всего неоднозначностью
синхронизации, а не доказанным несовпадением формы chirp.

## Результаты ToA и TDoA

AWGN-кампания дробного ToA содержит 500 детерминированных испытаний. Кампания
калиброванного 2D TDoA использует четыре приёмника вокруг области 100 x 80 м,
равномерно распределённые внутри источники, известные постоянные задержки
каналов и 1000 испытаний на каждый уровень шума timestamp.

| Шум timestamp одного приёмника | Сошлось | RMSE позиции | 95-й процентиль |
|---:|---:|---:|---:|
| 0,2 нс RMS | 1000/1000 | 0,063 м | 0,109 м |
| 1 нс RMS | 1000/1000 | 0,310 м | 0,537 м |
| 5 нс RMS | 1000/1000 | 1,582 м | 2,713 м |

![Точность калиброванного 2D TDoA](../images/tdoa-positioning-accuracy.png)

Это результат синтетической геометрии, а не характеристика текущего стенда.
Аппаратный ToA/TDoA всё ещё требует общей опоры и эпохи, sample counters в PL,
калибровки задержек кабелей/RF/ADC/DSP и измеренного бюджета неопределённости.

## Граница M1

Приёмник использует заданные SF, BW, sync word, IQ polarity и параметры
implicit header. Слепая классификация нескольких режимов, перекрывающиеся
LoRa-пакеты, подавление помех и потоковое real-time исполнение не входят в M1.
Детектор — вычислительно тяжёлый offline floating-point эталон. Эти честно
зафиксированные ограничения становятся входными данными для Simulink.
